# Geometry-LoT1 — the geometric intruder task

Replication of **Experiment 2** of Sablé-Meyer, Fagot, Caparos, van Kerkoerle,
Amalric & Dehaene (2021), *Sensitivity to geometric shape regularity in humans
and baboons: A putative signature of human singularity*, PNAS 118(16),
[doi:10.1073/pnas.2023123118](https://doi.org/10.1073/pnas.2023123118).

Six white quadrilaterals on a black screen, in two rows of three. Five are the
same shape, each with its own random rotation (±5°, ±15°, ±25°) and size
(0.875 … 1.125), and one is an **intruder** whose bottom-right vertex has been
displaced. The participant clicks on the intruder. The clicked shape turns
green (correct) or red (error), the intruder turns green, and a rising or
falling tone plays.

The 11 reference shapes range from the square to a fully irregular
quadrilateral (Table S1 of the paper's SI, transcribed in `shapes.go` and
checked by `shapes_test.go`). Human error rates rise steadily along this
regularity axis — from ≈2 % on the square to ≈40 % on the irregular shape —
which is the *geometric regularity effect* the paper reports; baboons show no
such effect.

`description.md` is the full specification extracted from the paper and the SI,
including the values the paper leaves open and the choices made here.

## Running

```bash
go run ./examples/Geometry-LoT1 -s 1        # from the repo root
go run ./examples/Geometry-LoT1 -w -s 1     # windowed
go run ./examples/Geometry-LoT1 -w -demo    # the 11 shapes and their 4 deviants
go run ./examples/Geometry-LoT1 -exp 1 -s 1 # Experiment 1 instead (see below)
```

| Flag | Meaning |
|------|---------|
| `-s N`, `-w`, `-d N` | subject, windowed mode, display — the standard goxpyriment flags |
| `-exp N` | which experiment of the paper: `2` (default) or `1` |
| `-demo` | draw the 11 reference shapes with their four deviants and exit |
| `-skip-training` | go straight to the test trials |
| `-iti MS` | inter-trial blank (default 500 ms) |
| `-feedback MS` | feedback display duration (default 700 ms) |

## Procedure

1. Instructions.
2. **Training A** — 10 trials with picture pairs. The originals (the baboons'
   training images: watermelon vs apple, letters, stars, gratings, …) were
   never published; `training.go` uses procedural vector stand-ins that keep
   the flavour of each pair.
3. **Training B** — 6 trials with the three easy polygon pairs (chevron vs
   pentagon, square vs triangle, triangle vs pentagon), each member once as
   the intruder.
   Both training blocks are repeated until ≥ 80 % correct.
4. **Test** — 11 shapes × 4 deviants × 2 presentations = **88 trials** in a
   single random order. In *canonical* trials five reference shapes surround
   one deviant; in *swapped* trials five deviants surround one reference shape
   (so "click the most irregular one" is not a strategy). The intruder's slot
   is balanced over the six positions.

Each trial: 500 ms blank → display until the click (no timeout; clicks on the
background are ignored) → 700 ms feedback.

## Experiment 1 (`-exp 1`)

The paper's first experiment (n = 605) differs from Experiment 2 in exactly
the ways listed in its SI:

| | `-exp 1` | `-exp 2` (default) |
|---|---|---|
| Colours | black shapes on white | white shapes on black |
| Layout | the six shapes on a circle around a central fixation mark | two rows of three |
| Composition | canonical only (the intruder is always the deviant) | half canonical, half swapped |
| Test trials | 11 × 4 = **44** | 11 × 4 × 2 = **88** |
| Training | 2 trials with polygon pairs, run once | 10 pictures + 6 polygons, each block to ≥ 80 % |

Shapes, deviants, rotations, scales, response and feedback are identical. The
`experiment` column of the data file records which variant produced each row.

## Deviants

The bottom-right vertex moves by 30 % of the matched mean pairwise vertex
distance (0.43 units): `shorter` / `longer` slide it along the bottom edge,
`rot_up` / `rot_down` rotate it about the bottom-left vertex (≈16.5°), which
keeps the edge length and breaks parallelism instead.

## Data

One CSV row per trial (training rows included, flagged by `phase`):
`trial, phase, block_repeat, shape, deviant, presentation, outlier_slot,
outlier_rotation, outlier_scale, rotations, scales, response_slot, correct, rt,
onset_ts`. `rt` is in ms from the display flip to the mouse-button event, both
on the SDL clock. `rotations` and `scales` are the six per-slot values
(`;`-separated, slot order 0–5, row-major from the top-left).

The paper's analysis: drop RTs above the overall 99th percentile, then error
rate per shape (11 points) and per shape × deviant (44 points).
