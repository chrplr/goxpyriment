In the Wisconsin Card Sorting Task, the participant  has to classify cards
according to different criteria. There are four different ways to
classify each card, and the only feedback is whether the
classification is correct or not. One can classify cards according to
the color of its symbols, the shape of the symbols, or the number of
the shapes on each card. The classification rule changes every 10
cards, and this implies that once the participant has figured out the
rule, the participant will start making one or more mistakes when the
rule changes. The task measures how well people can adapt to the
changing rules.

The cards are available in ./stimuli/*.png files

On each trials, a first row in the upper half of the screen shows 4 cards, which differ in the color of the symbol, the shape of the symbol and the number of symbols.

A different card (randomly picked from the remaining set of cards) is displayed at the center of the screen and the user must select among the four top cards which s/he thinks belong to the same caterogie according to the current classication rule. Then he resvecd feedback (""good"" or "wrong").

The classicfication rules (color, shape or number) changes reandomly after 6 to 10 correct trials.

More details are available at https://en.wikipedia.org/wiki/Wisconsin_Card_Sorting_Test
