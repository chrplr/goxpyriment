Memory Span

An adaptive immediate-serial-recall task — built with goxpyriment, running in your browser via WebAssembly.

You will see sequences of digits, letters or words, one item per second. After each sequence, click the on-screen buttons to reproduce it in the same order. Correct sequences get longer, errors make them shorter. There are 30 trials.

Before you start

  • Use a focused, foreground tab: browsers throttle background tabs and frame timing degrades.
  • Responses are mouse clicks, so a real pointer works best.
  • Pressing Start also unlocks audio (browsers keep sound suspended until the first user gesture) — a buzzer marks incorrect trials.
  • When the 30 trials are over, your browser downloads one file, Memory Span_sub-<id>_date-<date>-<time>.zip. It holds the .csv with one row per trial and the matching -info.txt with the session metadata. If your browser asks where to save it, say yes — that archive is the whole session.
  • Press ESC at any time to abort.
