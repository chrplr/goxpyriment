# Hermann Grid (goxpyriment)

Go port of `grid_expyriment.py`, displaying the
[Hermann grid illusion](https://en.wikipedia.org/wiki/Grid_illusion).

A regular array of black squares is drawn on a gray background. The gaps between
the squares form "streets"; grayish smudges seem to appear at every intersection
*except* the one you are fixating. Nothing is drawn there — it is a lateral
inhibition artefact of early visual processing.

## Usage

From the repository root:

```bash
go run ./examples/demo_Hermann_grid -w
```

### Keys

- `RIGHT` — widen the gap between cells (up to 100 px)
- `LEFT` — narrow the gap (down to 1 px)
- `ESC` — quit

The illusion is strongest for a particular gap/cell ratio, so sweeping the gap
with the arrow keys is the point of the demo.

### Flags

- `-rows N`, `-cols N` — grid dimensions (default 10 × 10)
- `-cell F` — side length of one cell in pixels (default 50)
- `-space F` — initial gap between cells in pixels (default 10)
- `-nohint` — hide the on-screen key legend
- `-w` — windowed mode (1024×768)
- `-d N` — display index (-1 = primary)
- `-s ID` — subject ID (unused; kept for API consistency)

## Differences from the Python original

- The grid is centered exactly; the Expyriment version was offset by half a cell
  because it used the "left/top" corner value as Expyriment's `position`
  (which is a *center*).
- A legend line reports the current gap width, so the setting that produces the
  strongest illusion is readable rather than guessed. Pass `-nohint` for a bare
  grid.
