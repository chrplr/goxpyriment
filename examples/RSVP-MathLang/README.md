MathLang RSVP paradigm
======================

MathLang RSVP paradigm for fMRI: sentences are presented word by word
(300 ms per word, no blank between words) on a fixed onset schedule
started by the scanner ('t') trigger. Nine sentence types (pseudoword lists, word
lists, meaningless sentences, factual/contextual knowledge, theory of
mind, arithmetic principles, calculation, geometry) in true and false
variants contrast the language and mathematical reasoning
networks. 


Onsets are read from the per-subject table
stim_lists/sub-NNN_task-MathLang.csv; each of the 5 blocs is a
separate run, selected with -b.

     go run . -s 1 -b 1   # run subject 1, run 1


Task and responses
------------------

The participant judges the veracity of each statement with two buttons:

     1 = VRAI (true)      2 = FAUX (false)

The expected answer is the first character of the `truth_val` column
(V = vrai, F = faux); a second character, where present (FP, FC, VV,
VF, ...), encodes a sub-condition and is ignored when scoring.

Presses are accepted from the onset of the first word until the next
sentence is due; the first press of the trial counts and later ones are
discarded. Reaction time is measured from the onset of the first word
-- so it includes the reading time -- using the SDL3 hardware event
clock. The final sentence of a bloc, having no following onset, gets a
6 s window.

Each trial adds `expected`, `response`, `correct` and `rt` (ms) to the
data file; unanswered trials record `n/a`. At the end of the bloc a
summary is printed to the console, overall and per condition:

     bloc 1 summary
       condition                   n %correct  median RT missed
       01-PseudowordList          16     93.8       1420      1
       ...
       ------------------------ ---- -------- ---------- ------
       ALL                        72     91.7       1508      3

Percent correct is computed over every sentence presented, so an
unanswered trial counts as an error (the `missed` column reports how
many). The median RT is over answered trials only, correct and
incorrect alike.


Flags
-----

     -s N     subject ID; selects stim_lists/sub-NNN_task-MathLang.csv
     -b N     bloc (fMRI run) to present, 1-5 (default 1)
     -on N    duration of each word, in ms (default 300)
     -off N   blank between words, in ms (default 0)
     -w       windowed mode (1024x768), for testing
     -d N     display index (-1 = primary)

The word rate is set by -on and -off: each word is shown for -on ms,
followed by a blank of -off ms, so the word-to-word SOA is their sum.
The defaults (300/0) present the words continuously, with no gap.

     go run . -s 1 -b 1 -on 250 -off 150   # slower, with a blank between words

Raising -on/-off lengthens each sentence, and a sentence must finish
before the next one is due. At the defaults the longest sentence
(11 words) takes 3.3 s, well inside the 5.6 s minimum onset-to-onset
interval; the program warns at startup if a chosen rate would overrun
the schedule.


Notes:

1. This is a variant of the Mathlang paradigm first described in  Amalric, M. & Dehaene, S. (2016). Origins of the brain networks for advanced mathematics in
expert mathematicians. PNAS 113(18), 4909-4917.

   See also Moreno, A., Amalric, M., Pietrantoni, M., Becuwe, S., Thirion, B., Pallier, C., Dehaene-Lambertz, G., & Dehaene, S. (2025). Languages of the brain: fMRI dissection of the amodal networks for language, mathematics, and social knowledge (p. 2025.12.19.695075). bioRxiv. https://doi.org/10.64898/2025.12.19.695075


2. The individual stimuli lists were generated by:

         cd stims_lists
         python generate-subject-csvs.py
