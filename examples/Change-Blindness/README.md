# Change Blindness — Rensink Flicker Paradigm

Demonstrates **change blindness**: large changes to a visual scene are surprisingly hard to detect when the change is hidden by a brief blank interval between alternating images. 

A 5×5 grid of coloured squares flickers between two versions (A and A′) with blank screens in between. Exactly one cell differs in colour between A and A′. The flicker cycle repeats until the participant responds by pressing the Spacebar, or a 10-second timeout occurs.

## Timing (Rensink formula)

| Phase | Duration |
|-------|----------|
| Image A | 240 ms |
| Blank | 80 ms |
| Image A′ | 240 ms |
| Blank | 80 ms |

## Controls / Response keys

| Key | Meaning |
|-----|---------|
| Space | Change detected |

If no response is given within 10 seconds the trial is recorded as a miss.

## Output

Data are saved to `goxpy_data/` as a `.csv` file. One row per trial:

| Column | Description |
|--------|-------------|
| `trial` | Trial number |
| `change_row` | Row index of the changed cell (0-based) |
| `change_col` | Column index of the changed cell (0-based) |
| `color_before` | Cell colour in image A |
| `color_after` | Cell colour in image A′ |
| `rt_ms` | Reaction time in milliseconds (−1 if timed out) |
| `detected` | `true` if participant responded within the timeout |

## Key Theories Explaining Change Blindness

Change blindness—the inability to notice significant visual changes when accompanied by a visual disruption (such as a blink, a saccade, or a flicker)—is explained through several key theoretical frameworks in visual cognition.

### 1. Attentional Bottleneck & Coherence Theory

* **Core Idea:** Proposed prominently by Ronald Rensink and colleagues, this model posits that without visual attention, visual representations are volatile and transient.
* **Mechanism:** The visual system continuously builds rapid, low-level "proto-objects," but focused attention acts as a bottleneck or "glue" required to consolidate these into stable visual representations (coherent objects) in visual short-term memory (VSTM). If a global transient (like a blank screen) wipes out the local motion signals that usually draw automatic attention to a change, you fail to compare the pre-change and post-change representations unless attention was already deployed to that specific item.

### 2. Overwriting / Representation Failure Hypothesis

* **Core Idea:** Early theories suggested that change blindness occurs because the incoming visual input overwrites the pre-change visual representation in visual memory.
* **Mechanism:** When the post-change scene appears, it updates or destroys the fragile iconic memory trace of the original scene before a comparison process can take place.

### 3. Comparison Failure / Inaccessibility Hypothesis

* **Core Idea:** Rather than failing to store or encode the initial representation, change blindness often results from a failure to **compare** the stored pre-change memory with the current post-change perception.
* **Mechanism:** Studies using implicit bias or priming show that observers often retain detailed information about pre-change objects at an implicit or pre-conscious level, but they fail to actively retrieve or compare these representations unless explicit context or top-down cues prompt them to do so.

### 4. Predictive Processing & Top-Down Expectation Models

* **Core Idea:** Under Bayesian and predictive processing models, the visual system does not construct an exhaustive frame-by-frame record of the visual world; instead, it generates a top-down predictive model based on priors, semantic scene context, and visual gist.
* **Mechanism:** The brain minimizes prediction errors by updating only elements that carry relevant semantic or behavioural significance. Changes that do not alter the overall "gist" or semantic continuity of a scene are filtered out as non-essential noise.

### 5. Corollary Discharge & Eye Movement Accounts

* **Core Idea:** When changes coincide with eye saccades, the brain uses a corollary discharge signal (CDS)—a motor copy sent to visual processing centers—to suppress transient motion cues (saccadic suppression) and maintain spatial stability.
* **Mechanism:** Because visual transients are suppressed during eye movements or artificial visual gaps, the brain relies heavily on top-down continuity assumptions, missing local changes that lack strong visual or top-down saliency.

* **Overview of Mechanisms, Attention, and Memory:** A comprehensive review framing change blindness across perception, attentional allocation, working memory capacity, and top-down processing examines how visual representations are compared across disruptions and highlights how change blindness serves as a window into the architecture of visual awareness (Frontiers in Humanities and Social Sciences, 2026).

* **Classic Foundation:** For the foundational theoretical frameworks establishing attentional dynamics and flicker paradigm methodologies, see Rensink, O'Regan, & Clark (1997) (*Psychological Science*), as well as Simons & Levin (1997) (*Trends in Cognitive Sciences*).
