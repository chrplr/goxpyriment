Your task is to implement the experimental paradigm described in Hart et al. (2022). The software consists of two sequential tasks:  Geometric Reasoning Task (Verbal categorical judgments about planar triangle properties given visual shape/size transformations).  Vertex Localization Task (Visual extrapolation / completion of missing triangle vertices using a point-and-click mouse interface).  1. Display Environment & Global ParametersTarget Hardware Display: Large-screen presentation ($65''$ diagonal, $1920 \times 1006\text{ px}$ resolution).  Coordinate Unit Definition: $1\text{ length unit} = 1632\text{ px}$ ($1920\text{ px} \times 0.85$).  Input Hardware: Single-button mouse.  Trial Sequence Order: Participants always complete the Reasoning Task first, followed immediately by the Localization Task.  2. Correlated Random Walk (CRW) Simulation EngineImplement the computational model describing visual extrapolation paths:  $$\frac{d^2\theta}{dt^2} = \frac{1}{\tau} \left( \frac{1}{\xi}(\theta - \theta_0) - \frac{d\theta}{dt} \right) + \eta(t)$$$$\frac{dx}{dt} = v_p \cos(\theta), \quad \frac{dy}{dt} = v_p \sin(\theta)$$Where:$\theta_0$: Target corner angle trajectory.  $\tau$: Inertial relaxation timescale for local motion smoothness.  $\xi$: Timescale parameter for global error correction (angle preservation).  $v_p$: Extrapolation propagation speed.  $\eta(t)$: Gaussian noise term.  The model must calculate the Scaling Exponent ($\alpha$) by fitting the power-law slope of estimate variance vs. triangle side length:  $$\log(\text{SD}_y) \sim \alpha \log(\text{Side Length})$$$\alpha \approx 0.5$ indicates strong global error correction (high fidelity to Euclidean scale invariance).  $\alpha \approx 1.0$ indicates uncorrected local random noise.
