Reading-1

Lexical decision with per-letter visibility sampling — built with goxpyriment, running in your browser via WebAssembly.

On each trial a string of five letters is flashed for about a fifth of a second, then replaced by #####. Some of the letters are faint, and which ones are faint keeps changing during the flash — that is intentional, so just report what you saw.

Decide whether the string was a real English word: press F if it was a word, J if it was not. There are 8 practice trials (with feedback) and then 100 test trials.

Before you start

  • Use a focused, foreground tab: browsers throttle background tabs and frame timing degrades.
  • This task is keyboard-only — SPACE to move past each instruction screen, then F / J to answer. Keep the canvas focused; click it if a key seems ignored.
  • Work in a dimmed room if you can. The faint letters are drawn at 25 % of full luminance, and a bright screen or a strong reflection washes out exactly the manipulation being measured.
  • When the 100 trials are over, your browser downloads one file, Reading-1_sub-<id>_date-<date>-<time>.zip. It holds the .csv with one row per trial — including the 20 per-letter visibility values — and the matching -info.txt with the session metadata. If your browser asks where to save it, say yes — that archive is the whole session.
  • Press ESC at any time to abort.

A note on timing

  • The stimulus is built from four 50 ms windows, which is three display refreshes each at 60 Hz. The browser paces frames through requestAnimationFrame, so a dropped frame lengthens a window rather than being reported. The measured duration of every trial is written to the CSV as stim_dur_ms — check it before trusting a session.
  • On a display that is not 60 Hz, a 50 ms window is rounded to the nearest whole number of refreshes (7 at 144 Hz = 48.6 ms). The -info.txt records what was actually used.
  • For results that depend on exact stimulus onset, run the native build instead. See docs/WASM.md.
