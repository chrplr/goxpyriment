# build-wasm-apps.sh. One name per line; everything after '#' is a comment.
#
# The browser has no filesystem, so any program that reads its stimuli from a
# path fails at run time -- it still *compiles* for GOOS=js, which is why this
# list exists rather than relying on the build to reject them.
#
# Fixing one is mechanical: replace the path-based loader with //go:embed plus
# the in-memory constructor (examples/demo_spritesheet/main.go:25 is the model,
# and 20 example files already do it). Then delete the line from this file.

demo_play_videos                 # os.ReadDir("assets")
demo_play_two_videos             # os.ReadDir("assets")
demo_play_two_gvvideos           # os.ReadDir("assets")
demo_play_gv_videos              # -f defaults to a .gv path on disk
demo_bouncing_gv_movies          # os.Stat on .gv paths
