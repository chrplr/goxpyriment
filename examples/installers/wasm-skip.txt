# Examples that cannot run in a browser, and are therefore not bundled by
# build-wasm-apps.sh. One name per line; everything after '#' is a comment.
#
# The browser has no filesystem, so any program that reads its stimuli from a
# path fails at run time -- it still *compiles* for GOOS=js, which is why this
# list exists rather than relying on the build to reject them.
#
# Fixing one is mechanical: replace the path-based loader with //go:embed plus
# the in-memory constructor (examples/demo_spritesheet/main.go:25 is the model,
# and 20 example files already do it). Then delete the line from this file.

demo_sync_two_gv_movies          # drives a hardware trigger over a serial port
demo_images                      # reads its images from disk with filepath.Glob
demo_stream_images               # reads its images from disk with filepath.Glob
demo_play_videos                 # reads its videos from disk with os.ReadDir
demo_play_two_videos             # reads its videos from disk with os.ReadDir
demo_play_two_gvvideos           # reads its videos from disk with os.ReadDir
demo_play_gv_videos              # takes the path of a .gv file on disk
demo_bouncing_gv_movies          # takes the paths of .gv files on disk
RSVP-Images                      # reads its images from disk with os.Open
RSVP-Images-OneBack              # reads its images from disk with filepath.Glob
Language-Localizer-French-audio  # requires a stimulus CSV given on the command line
Mental-Rotation-3D               # generates its stimuli onto disk before running
