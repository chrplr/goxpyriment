# Console timing report

`console-timing-report.src.html` is the report; `build.py` inlines the figures
from `../figures/` and writes the standalone `console-timing-report.html`, which
is gitignored — it is 0.7 MB of base64 and regenerates in a second.

Published as a Claude artifact at
<https://claude.ai/code/artifact/0c3b4be5-8fd4-49fa-b611-754ec19c45b9>.
Republishing that same URL updates the page in place.

The numbers come from the four runs of 8 August 2026, raw captures in
`~/goxpy_data/paper-timing/`, and are the same ones in
`docs/TimingMegastudyComparison.md`. Change them in both or in neither.
